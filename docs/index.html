产品介绍 · PRODUCT

认识 Harmony Care Agent
它把家庭变成一个"懂你"的世界

Harmony Care Agent 是一个"以家庭为单位"的分布式智能陪伴体。它不只陪单个用户说话，而是把家庭视为一个持续运转的世界——里面有老人、儿童、机器人、房间、设备、传感器和风险区域。它理解这个世界的状态，定义要看护的目标，调度设备能力去执行，再用反馈闭环把每一次结果收束成长期记忆。

01

Home World Model 家庭空间世界模型

统一表达老人、儿童、机器人、房间、设备、传感器和风险区域。所有决策都基于同一份世界状态，避免数据口径不一致。

02

Hybrid Safety 混合安全决策

跌倒、儿童独处门口事件等高风险场景由确定性规则优先保护；普通陪伴使用受控模型输出。安全永远在模型之前。

03

CareGoal / Agent Plan 看护目标与计划

先定义要保护什么（如"避免老人跌倒后无人响应"），再形成可解释的行动步骤。设备动作由能力层匹配，而非前端硬编码。

04

Harmony Device Capability 鸿蒙设备能力层

机器人、灯光、门锁、智慧屏、Watch、Phone 均经 Mock Adapter 产生可验证执行结果；离线设备不会被选择，保证不会向不存在的设备下发指令。

05

Feedback Closed Loop 反馈闭环与事件记忆

显式反馈会更新世界状态，触发 Goal Evaluation 和必要的 Follow-up，再收束事件记忆。每一次"做了没做成"都被认真记录与回放。

快速启动 · QUICK START

从干净环境启动 后端 + 前端

需要 Python 3.10+、Node.js 20+。Mock Mode 无需 API Key，全部比赛 Demo 可离线可重复运行。

Terminal 1 · Backend

# 后端（FastAPI）
cd backend
python -m pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

健康检查：http://localhost:8000/api/health

Terminal 2 · Frontend

# 前端（Next.js）
cd frontend
npm install
npm run dev

打开：http://localhost:3000
/lab 演示：http://localhost:3000/lab

API 概览 · API

Mock-only 后端 端点

以下端点覆盖家庭历史加载、事件触发、目标反馈、Context 导入与重置。Mock Mode 下全部返回本地可预测结果，不消耗真实模型 Token。

MethodEndpoint用途
GET/api/demo/histories获取静态家庭历史选项
POST/api/demo/histories/{history_id}/load加载历史并清除旧 Runtime Goal
POST/api/events/trigger触发 Current Event 并执行 Care Agent
POST/api/goals/{goal_id}/feedback提交当前 Goal 的显式反馈
POST/api/context/upload导入 JSON Context 或 TXT / MD 规则
POST/api/reset?preset_id=...重置到兼容 Preset

Validation · 自检

# 后端测试强制 MOCK_MODE=true
cd backend && python -m pytest

# 前端类型 + 构建
cd ../frontend && npx tsc --noEmit && npm run build
